系統介紹

本系統是公司內部的都更案件管理平台，將案件進度、地主資料、土地及建物謄本、文件、費用與作業工具集中管理。

主要功能包含：

  • 工作看板：查看行事曆、地主跟進事項及案件待辦。
  • 案件管理：建立案件、管理進度及執行 SOP。
  • 謄本辨識：擷取土地與建物謄本資料，輔助建立登記清冊。
  • 地主資料管理：管理所有權人資料、聯絡紀錄及同意狀態。
  • 文件與費用：管理案件文件、登錄費用及掃描發票。
  • 計算工具：製作清冊及試算土地增值稅。
  • 公司資源：查詢公版文件、法規、新聞、相關網站及知識庫。

系統依使用者角色與案件成員身分提供不同的操作權限。

登入與介面導覽

2.1 登入系統

  1. 開啟都更管理系統網站。
  2. 輸入公司提供的帳號與密碼。
  3. 點擊登入。
  4. 登入成功後，進入系統操作介面。

若忘記帳號或密碼，請聯絡系統管理員協助處理。

案件管理

  • 查看公司案件清單。
  • 搜尋指定案件。
  • 進入案件操作介面。

新手快速上手

建議第一次操作系統的同仁依照下列順序建立案件。

步驟一：建立新案件

  1. 進入總覽頁面。
  2. 點擊+ 新增案件。
  3. 填寫案件名稱、縣市等基本資料。
  4. 儲存後，至案件管理找到該案件。

新增案件功能依帳號權限開放。

步驟二：啟動 SOP 流程

  1. 進入指定案件。
  2. 開啟SOP 進度頁籤。
  3. 展開第 0 關初始核定立案。
  4. 上傳投報表。
  5. 確認檢核項目完成後，完成本關卡。

步驟三：匯入土地及建物謄本

  1. 展開第 1 關籌備階段。
  2. 上傳地籍圖。
  3. 上傳土地及建物謄本。
  4. 等待系統解析登記資料。
  5. 核對土地地號、建號、所有權人、面積、持分及其他登記資訊。
  6. 修正辨識錯誤後執行匯入。

注意： AI 與 OCR 辨識結果僅供輔助，匯入前仍須由操作人員與原始謄本逐筆核對。

步驟四：建立地主清冊

  1. 確認匯入後的登記資料正確。
  2. 返回 SOP 第 1 關。
  3. 點擊確認地主清冊正確。
  4. 系統自動產生 Excel 清冊。
  5. 下載並檢查清冊內容。

後續需要調整登記或地主資料時，可透過整合清冊與樓棟視圖操作。

步驟五：開始地主聯絡與同意管理

完成前期資料整理後，即可依案件進度進行地主聯絡、說明會及同意書管理，系統會依相關紀錄計算聯絡率與同意度。

案件 SOP 操作說明

SOP 用於管理都市更新案件各階段的檢核事項。

每個關卡均有對應的文件、資料或完成條件。確認所有必要項目符合要求後，才可完成該關卡。

預設 SOP 流程

關卡階段名稱主要工作
0初始核定立案上傳投報表
1籌備階段地籍圖、謄本匯入、資料校正及清冊確認
2地主拜訪建立聯絡紀錄，聯絡率達 95%
3都更說明會上傳說明會簡報並完成主管審核
4意願書簽署人數與土地持分同意率均達 80%
5圖面規劃與估價上傳規劃圖面、顧問及估價文件
6第 2 次都更說明會上傳說明會、同意書、合約及相關簽核文件
7合約說明會上傳說明會簡報並完成主管審核
8簽約會再次確認雙門檻同意度
9送件審查最終確認雙門檻同意度及送件條件

關卡操作規則

  • 關卡進行中，可修正或重新上傳尚未完成的資料。
  • 所有必要檢核項目完成後，才可完成關卡。
  • 已完成的整個關卡不可退回。
  • 管理者可透過自訂關卡流程調整尚未開始的未來關卡。
  • 需要主管審核的檢核項目，須由具備對應權限的管理層確認。

表中的聯絡率與同意度數值為目前系統預設 SOP 條件，不應直接視為所有都市更新案件通用的法定門檻。

案件內功能介紹

5.1 SOP 進度

集中管理案件各階段的執行進度、檢核項目、文件上傳及關卡完成狀態。

5.2 整合清冊

提供土地、建物與所有權人的整合資料，可依聯絡結果、持分類型、地號段別及樓層等條件篩選。

亦可編輯土地登記中供土地增值稅試算使用的原規定地價或前次移轉現值。

5.3 樓棟視圖

以建物門牌及樓層呈現案件內各戶資料。

  • 格內顏色表示同意狀態。
  • 角標數字表示該戶共有人數。
  • 點擊格子，可查看或編輯地主資料。
  • 可新增及管理地主聯絡紀錄。

共有部分與純地下室建號不作為一般獨立戶顯示。

5.4 地主聯絡簿

集中查閱地主姓名、門牌、電話及戶籍地址，方便外出拜訪及聯絡前快速核對。

詳細聯絡紀錄須至地主編輯視窗查看或管理。

5.5 文件

集中管理案件相關文件及同意書狀態。

同意書狀態會影響系統的同意度統計，因此修改時應確認紀錄正確。

5.6 他項權利部

查看及管理土地或建物登記相關的抵押權、地上權等他項權利資料。

5.7 費用

登錄案件支出及相關費用資訊，可搭配發票掃描工具輔助輸入。

5.8 土增稅

針對案件內土地資料進行土地增值稅概算，並顯示不同稅率試算結果。

5.9 人員

查看案件參與人員，具備管理權限的使用者可新增或移除案件成員。

功能區工具使用教學

6.1 謄本辨識

功能用途： 將土地及建物謄本轉換成可供案件管理使用的結構化資料。

操作流程：

  1. 開啟案件的SOP 進度。
  2. 進入第 1 關籌備階段。
  3. 選擇上傳土地及建物謄本。
  4. 系統優先擷取電子謄本的文字內容。
  5. 對無法擷取的部分使用 OCR 補充辨識。
  6. 使用 AI 輔助校正、比對欄位。
  7. 人工確認辨識結果。
  8. 執行資料匯入。

應特別檢查所有權人、土地持分、建物面積及他項權利等重要資料。

6.2 清冊製作

功能用途： 依案件登記資料產生 Excel 清冊。

操作流程：

  1. 完成土地及建物謄本匯入。
  2. 核對整合資料。
  3. 於 SOP 第 1 關執行清冊確認。
  4. 系統產生 Excel 檔案。
  5. 下載並確認輸出結果。

匯出檔案名稱為案件名稱清冊.xlsx。

6.3 發票掃描

功能用途： 透過發票 QR code 或 OCR 辨識，減少案件費用輸入作業。

操作流程：

  1. 進入案件的費用頁籤。
  2. 新增支出紀錄。
  3. 拍照或上傳電子發票證明聯。
  4. 系統優先辨識 QR code，無法讀取時再使用 OCR。
  5. 檢查未稅金額、營業稅及總金額。
  6. 確認資料回填正確後儲存。

6.4 計算土地增值稅

功能用途： 根據案件土地登記資料，進行土地增值稅初步估算。

操作流程：

  1. 進入案件整合清冊，確認原規定地價或前次移轉現值。
  2. 開啟土增稅頁籤。
  3. 選擇要試算的地主及土地資料。
  4. 輸入本月申報移轉現值。
  5. 儲存後查看試算結果。

重要提醒： 系統提供的是概算。持有年限減徵、物價指數調整、土地改良費用及相關租稅優惠等因素未完整納入，正式稅額以稅捐稽徵機關核定為準。

6.5 製作同意書

目前功能區標示為即將推出。

預定用途為依地主、土地及建物資料輔助製作都市更新事業計畫同意書。正式開放前，不應將此功能列為已可操作的步驟。

常見問題

Q1：忘記登入密碼怎麼辦？

請聯絡系統管理員協助處理帳號或密碼問題。

Q2：為什麼看不到某個案件？

請確認是否已被加入該案件的成員名單，以及目前帳號是否具備查看權限。

Q3：謄本辨識資料錯誤怎麼辦？

請先核對原始謄本，再於匯入確認或相關登記資料編輯位置修正。若屬舊案件缺少共有部分資料的情況，可能需要重新匯入謄本。

Q4：為什麼無法完成 SOP 關卡？

確認該關所有必要文件、資料及審核項目是否已完成。

Q5：地主聯絡率與同意度需要手動計算嗎？

不需要。系統會依登記資料、聯絡紀錄及同意書狀態進行彙算，但前提是來源紀錄正確。

Q6：為什麼無法新增或編輯資料？

可能受到帳號角色、案件成員身分或功能權限限制。請向管理者確認。

Q7：發票辨識後的金額錯誤怎麼辦？

請核對原始發票與辨識欄位，修正後再儲存費用紀錄。

Q8：清冊資料修改後，已下載的 Excel 會同步更新嗎？

已下載的檔案不會自動同步。請重新產生及下載最新清冊。

Q9：系統畫面未更新怎麼辦？

可先重新整理瀏覽器，再確認資料是否已成功儲存。

Q10：土地增值稅試算結果可直接用於正式申報嗎？

不可以。系統結果僅供初步估算，正式稅額仍應由主管稅捐機關核算。

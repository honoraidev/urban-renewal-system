系統是什麼

本系統把都市更新案件從籌備立案到雙門檻同意達標的作業集中管理,主要涵蓋:

  • 謄本檔案匯入 → 土地／建物登記、地主資料的建立與校正
  • 地主聯絡紀錄、聯絡率統計
  • 同意書管理、同意度(人數 + 土地持分雙門檻)試算
  • SOP進度與檢核清單
  • 案件文件庫、費用登錄(可用OCR掃描)、土地增值稅試算
  • 地主清冊 Excel 匯出
角色可做的事
管理者 / 主管建立／刪除案件、指派案件人員、使用者管理、看登入紀錄,所有資料可編輯
承辦 / 編輯者被指派案件的登記資料、聯絡紀錄、文件、費用、SOP 操作
檢視者唯讀

看不到某個頁籤或按鈕,通常是角色權限,或「不是這個案件的成員」。請管理者調整。

登入與介面導覽

以帳號密碼登入,若忘記帳號與密碼請聯絡管理員。左側選單分區:

  • 總覽 — 工作看板(左側行事曆、今日要跟進的地主、提醒事項:今天的行事曆事項 + 各案件這階段還沒完成的 SOP 待辦)、案件總覽(所有案件的關卡狀態一覽)。
  • 案件管理 — 依縣市分組的案件清單,點案件名稱進入該案件。
  • 工具與資源 — 公版文件、新聞、相關法規、相關網站、Q&A 知識庫、部門物品管制表。
  • 系統指南 — 本使用手冊、功能區。

側邊欄可點側邊欄頂端的收合按鈕收合;收合狀態下點「案件管理」「工具與資源」「系統指南」的圖示,會在圖示旁邊彈出小浮窗顯示裡面的項目,不用整條展開側邊欄。各頁面最上方有「首頁 › ...」麵包屑,點「首頁」統一回到工作看板。

右上角頭像:編輯個人資料、切換深／淺色、登出;管理者另有「使用者管理」「登入紀錄」。手機版左上角 ☰ 開合側欄。

快速上手

  1. 總覽頁右上 「+ 新增案件」,填案件名稱、縣市等基本資料。
  2. 從左側「案件管理」點進該案件,在 SOP 進度 頁籤。
  3. 展開 第0關「初始核定立案」,上傳投報表,確認後完成本關。
  4. 展開 第1關「籌備階段」,上傳地籍圖;上傳土地登記／建物謄本,兩者逐筆對照謄本校正(地號、建號、所有權人、持分分子／分母、面積、他項權利、戶籍地址),確認無誤後一鍵匯入,再點 「確認地主清冊正確」,系統會自動下載檔名為「案件名稱清冊.xlsx」的清冊。

若後續須修地主資料,可至整合清冊與樓棟視圖修改。

之後依序推進第2關以後:在樓棟視圖頁面可記錄各地主的聯絡狀況、文件頁維護同意書、系統即時算聯絡率與同意度。

SOP逐關說明

在 SOP 進度 頁籤逐關推進。每關展開後有檢核清單,必要文件／資料補齊並勾選確認後,才能按「完成本關卡」;已完成的關卡不可退回。管理者可以在 SOP 頁點「自訂關卡流程」調整關卡順序、名稱與門檻條件 —— 只能調整還沒跑到的未來關卡,已完成或正在進行的關卡不受影響。

「不可退回」指的是整關完成後不能重來;關卡進行中,檢核清單裡的個別項目還是可以重新操作 —— 例如第1關的「上傳土地／建物謄本」可以重新上傳,「確認地主清冊正確」也可以先取消確認、修正資料後再重新確認,不受影響。

預設關卡檢核清單重點
第0關 · 初始核定立案上傳投報表
第1關 · 籌備階段上傳地籍圖;匯入並校正土地與建物謄本;確認地主清冊正確、產出 Excel
第2關 · 地主拜訪建立地主聯絡方式,聯絡率達 95% 門檻
第3關 · 都更說明會上傳說明會簡報,主管審核通過
第4關 · 意願書簽署雙門檻同意度:人數同意率、土地持分同意率兩者都要 ≥ 80%
第5關 · 圖面規劃與估價上傳顧問文件、建築圖面、估價結果,主管審核通過
第6關 · 第2次都更說明會上傳說明會簡報、同意書、合約、董事長簽核之投報表、分坪、邀請函,主管審核通過
第7關 · 合約說明會上傳說明會簡報,主管審核通過
第8關 · 簽約會雙門檻同意度再次確認 ≥ 80%
第9關 · 送件審查雙門檻同意度最終確認 ≥ 80%

同意度與聯絡率是由「登記資料」「地主聯絡紀錄」「文件(同意書狀態)」的資料即時彙算的,不用手動填百分比;「主管審核通過」這類項目只有管理層(L0~L2)可以確認。

功能區工具操作

系統指南 › 功能區 集中列出跨案件工具,每張卡片有「立即使用」,點下去直接跳到該功能所在的案件分頁(需先從左側選一個案件)。

謄本辨識

  1. 進入案件 → SOP 進度 › 第1階段・籌備階段 › 上傳土地跟建物謄本。
  2. 電子謄本直接抽文字;掃描件或抽不到的欄位,系統自動 OCR 補掃再用 AI 校正比對還原地址與欄位。
  3. 檢視辨識結果確認無誤 → 一鍵匯入,產出初版登記清冊。

清冊製作

  1. SOP 第1關展開,先完成上傳地籍圖與土地／建物謄本、逐筆校正。
  2. 在「確認地主清冊正確」步驟點 「確認」,自動產生 Excel 清冊檔案。
  3. 「層次面積」欄依各案件實際樓層動態產生;「建物總面積 = Σ 層次各格 + 附屬」「權狀面積 = 建物總面積 + 共有持分」。面積欄一律計算到小數點後 2 位。

發票掃描

  1. 案件 → 費用 頁新增支出時,拍照或上傳電子發票證明聯。
  2. 優先讀 QR code 精準取值;讀不到再用 OCR。
  3. 自動互算未稅金額、營業稅、總計並回填表單,確認後儲存。

計算土地增值稅

  1. 案件 → 土增稅 頁,系統自動帶入該案地主與地號。
  2. 「原規定地價／前次移轉現值」到 整合清冊 上編輯(土增稅頁唯讀)。
  3. 在土增稅頁填「本月申報移轉現值」→ 儲存,自動同時試算自用／一般稅率的應納稅額。

土增稅為概算,未套用持有年限減徵、自用住宅優惠稅率、物價指數調整、土地改良費用等,正式稅額以地方稅捐稽徵機關核算為準。

常見問題

  • OCR 匯入後數字怪怪的? 到「整合清冊」逐筆對照謄本校正;OCR 是輔助,一切以謄本為準。
  • 舊案件缺共有建號／共有持分資料? 該功能是後來加的,舊案要重新用 OCR 匯入該案謄本才會帶入。
  • 關卡按不了「完成」? 展開該關檢核清單,把必要文件與確認項目補齊。
  • 清冊的建物總面積和各欄加起來不一樣? 新版已修正(含地下層);若還有請重新產生清冊,並確認整合清冊的樓層明細正確。
  • 畫面沒更新? 重新整理瀏覽器;系統會復原你剛剛看的頁面。
  • 下載的 Excel 開啟亂碼? 用 Excel 開啟(非文字編輯器);檔名為「案件名稱清冊.xlsx」。
